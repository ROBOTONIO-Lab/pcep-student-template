## 10–30′ · Bug hunt (διαφάνειες 8–9)

Τα 6 αρχεία είναι ήδη στο template repo (`lesson_04/bugs/`). Δεν λες τι φταίει. Λες: «διάβασε το μήνυμα δυνατά».

### bug_1.py — input χωρίς int
```python
age = input("Πόσων χρονών είσαι; ")
left = 18 - age
print("Σου μένουν", left, "χρόνια")
```
Σκάει: `TypeError: unsupported operand type(s) for -: 'int' and 'str'`
**Fix:** `left = 18 - int(age)` → `Σου μένουν 5 χρόνια`

### bug_2.py — παράνομα ονόματα (ΔΥΟ λάθη)
```python
my-score = 10
2nd = 20
print("Σύνολο:", my-score + 2nd)
```
Σκάει πρώτα στο `2nd`: `SyntaxError: invalid decimal literal`. Αφού το φτιάξουν, σκάει το `my-score`
(`SyntaxError: cannot assign to expression`). Καλή ευκαιρία για το «ένα λάθος τη φορά».
**Fix:** `my_score`, `second` (και στο print) → `Σύνολο: 30`

### bug_3.py — προτεραιότητα (ΔΕΝ σκάει)
```python
a = 10
b = 20
average = a + b / 2
print("Μέσος όρος:", average)
```
Τυπώνει `Μέσος όρος: 20.0` (λάθος, χωρίς μήνυμα).
**Fix:** `average = (a + b) / 2` → `Μέσος όρος: 15.0`

### bug_4.py — string που μοιάζει με αριθμό (ΔΕΝ σκάει)
```python
price = "12"
qty = 3
print("Σύνολο:", price * qty)
```
Τυπώνει `Σύνολο: 121212`.
**Fix:** `price = 12` → `Σύνολο: 36`

### bug_5.py — `/` αντί `//` (ΔΕΝ σκάει)
```python
minutes = 135
hours = minutes / 60
rest = minutes % 60
print(hours, "ώρες και", rest, "λεπτά")
```
Τυπώνει `2.25 ώρες και 15 λεπτά`.
**Fix:** `hours = minutes // 60` → `2 ώρες και 15 λεπτά`

### bug_6.py — Bonus: μοναδιαίο μείον και `**` (ΔΕΝ σκάει)
```python
x = -2
print(x ** 2, -2 ** 2)
```
Τυπώνει `4 -4`. Το `**` εκτελείται πριν το πρόσημο: `-2 ** 2` = `-(2 ** 2)`.
**Fix:** `print(x ** 2, (-2) ** 2)` → `4 4`

**Debrief (διαφάνεια 9, 3′):** μία γραμμή ανά bug + το νέο στοιχείο:
```python
print(-2 ** 2)      # -4
print((-2) ** 2)    # 4
print(-2 * -2)      # 4
```
Σημείο ελέγχου 30′: όλοι ≥ 4 commits. Αν όχι, bug 5–6 γίνονται σπίτι.

## 30–55′ · Το Ταμείο (διαφάνειες 10–12)

Νέο αρχείο `lesson_04/tameio.py`. Είσοδος δοκιμής πάντα: **12, 5, 6** (και πληρωμή **50**).

### Μέρος Α · v1 (30–42′)

**Βήμα 1.** Κεφαλίδα + σύνολο.
```python
print("=== ΤΑΜΕΙΟ ROBOTONIO ===")
total = 0
```

**Βήμα 2.** Πρώτο προϊόν. Γράψε ΠΡΩΤΑ τη μακριά μορφή, τρέξε, ΜΕΤΑ άλλαξέ τη:
```python
p1 = int(input("Τιμή 1ου προϊόντος; "))
total = total + p1        # → μετά: total += p1
print(total)
```
Ρώτα: «τι θα τυπώσει αν δώσω 12;» → 12. Τότε: «το `total = total + p1` το γράφουμε τόσο συχνά που η Python έχει συντομογραφία»: `total += p1`. Ίδιο αποτέλεσμα. Ανάφερε την οικογένεια: `-= *= /= //= %= **=`.

**Βήμα 3.** Άλλα δύο προϊόντα (το γράφουν μόνοι, 1′):
```python
p2 = int(input("Τιμή 2ου προϊόντος; "))
total += p2
p3 = int(input("Τιμή 3ου προϊόντος; "))
total += p3
```

**Βήμα 4.** Απόδειξη. Τρεις δοκιμές στη σειρά, να δουν τη διαφορά:
```python
print("-" * 24)
print(p1, p2, p3)                          # 12 5 6
print(p1, p2, p3, sep=" + ")               # 12 + 5 + 6
print(p1, p2, p3, sep=" + ", end=" = ")    # 12 + 5 + 6 =   (χωρίς αλλαγή γραμμής)
print(total, "€")                          # ... 23 €  στην ίδια γραμμή
```
Κράτα μόνο τις δύο τελευταίες. Έξοδος:
```
=== ΤΑΜΕΙΟ ROBOTONIO ===
Τιμή 1ου προϊόντος; 12
Τιμή 2ου προϊόντος; 5
Τιμή 3ου προϊόντος; 6
------------------------
12 + 5 + 6 = 23 €
```
`sep=` = τι μπαίνει ανάμεσα (default κενό). `end=` = τι μπαίνει στο τέλος (default `\n`).

**Βήμα 5.** Commit `Lesson 4: tameio v1`.

### Μέρος Β · v2 ρέστα (42–50′)

**Βήμα 6.** Μαζί:
```python
paid = int(input("Πόσα δίνει ο πελάτης; "))
change = paid - total
print("Ρέστα:", change, "€")
fives = change // 5
rest = change % 5
```
Ρώτα: «50 − 23 = 27. Πόσα πεντάευρα;» → `27 // 5 = 5`. «Τι μένει;» → `27 % 5 = 2`.

**Βήμα 7.** 🟡 Μόνοι τους (2′): δίευρα και μονόευρα από το `rest`.
```python
twos = rest // 2
ones = rest % 2
print(fives, "x 5€,", twos, "x 2€,", ones, "x 1€")
```
Έξοδος: `Ρέστα: 27 €` / `5 x 5€, 1 x 2€, 0 x 1€`. Commit `Lesson 4: tameio v2`.

### Μέρος Γ · v3 έκπτωση (50–55′)

**Βήμα 8.** Μία γραμμή, ΠΡΙΝ τη γραμμή `paid = ...`. Ρώτα πριν τρέξεις: «τι τύπο θα έχει το total;»
```python
total *= 0.9          # ίδιο με: total = total * 0.9
print("Με έκπτωση 10%:", total, "€")
print(type(total))
```
Έξοδος: `Με έκπτωση 10%: 20.7 €` / `<class 'float'>` και μετά `Ρέστα: 29.3 €`.
Σημείο: int × float → float. Ένας float αρκεί. Commit `Lesson 4: tameio v3`.

**Βήμα 9.** Terminal, `python3`, πληκτρολογούν μαζί σου (διαφάνεια 12):
```
>>> 0.1 + 0.2
0.30000000000000004
>>> 0.1 + 0.2 == 0.3
False
>>> 1.1 * 3
3.3000000000000003
>>> 1_000_000
1000000
```
Εξήγηση 1 πρότασης: το 0.1 στο δυαδικό είναι περιοδικό (όπως 1/3 στο δεκαδικό) και κάπου κόβεται. Εξεταστέο: ξέρουν ότι συμβαίνει, και ότι δεν συγκρίνουμε floats με `==`. Το `1_000_000` είναι literal syntax, 20 δευτερόλεπτα.

### Λύση Επίπεδο 2 · free_2.py
```python
seconds = int(input("Δευτερόλεπτα; "))
hours = seconds // 3600
rest = seconds % 3600
minutes = rest // 60
secs = rest % 60
print(hours, minutes, secs, sep=":")
```
`5000` → `1:23:20`

### Λύση Επίπεδο 3 · free_3.py
```python
distance = 384_400                      # km, Γη–Σελήνη
speed = int(input("Ταχύτητα σε km/h; "))
hours = distance / speed
print("Χρειάζεσαι", hours, "ώρες.")
total_hours = int(hours)
days = total_hours // 24
left = total_hours % 24
print("Δηλαδή", days, "μέρες και", left, "ώρες.")
```
`900` → `Χρειάζεσαι 427.1111111111111 ώρες.` / `Δηλαδή 17 μέρες και 19 ώρες.`
`100` → `Χρειάζεσαι 3844.0 ώρες.` / `Δηλαδή 160 μέρες και 4 ώρες.`

Αναμενόμενο κόλλημα στο 3: χωρίς `int()`, `427.11 // 24` → `17.0` και `% 24` → `19.11...`. Άσ' τους να το δουν και να ρωτήσουν.

### Συχνά σφάλματα σήμερα
- `total += int(input(...))` σωστό, αλλά αν ξεχάσουν το `int` → TypeError στο `+=`.
- `sep = ":"` με κενά γύρω από το `=` δουλεύει, αλλά PEP-8 λέει χωρίς κενά στα keyword arguments. Μην το κάνεις θέμα σήμερα.
- `print(hours ":" minutes)` χωρίς κόμματα → SyntaxError.
- Ρέστα αρνητικά αν ο πελάτης δώσει λιγότερα: δεν το χειριζόμαστε ακόμα — «αυτό θέλει `if`, επόμενο μάθημα».
