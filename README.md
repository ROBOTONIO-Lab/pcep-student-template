# pcep-games

Το προσωπικό μου repository για το PCEP 2026-2027 · ROBOTONIO-Lab.

Εδώ ζουν όλα τα παιχνίδια που γράφω στη διάρκεια της χρονιάς, στον φάκελο `games/`.
Οι απαντήσεις μου στις ερωτήσεις ✎ κάθε μαθήματος γράφονται στο `NOTES.md`.

## Πώς δουλεύω (κάθε μάθημα)

0. Στον υπολογιστή του εργαστηρίου: Chrome → εικονίδιο προφίλ → **Guest**. Δουλεύω μόνο μέσα στο παράθυρο Guest.
1. github.com → login → το repo `pcep-games`
2. **Code → Codespaces → Open** (την πρώτη φορά: **Create codespace on main**)
3. Γράφω τον κώδικα στον φάκελο `games/`
4. Τρέχω: κουμπί ▶ πάνω δεξιά, ή στο terminal `python games/αρχείο.py`
5. Αποθηκεύω στο GitHub: **Source Control** (αριστερά) → μήνυμα → **Commit** → **Sync Changes**
6. Στο τέλος κλείνω το παράθυρο Guest. Τίποτα δεν μένει στον υπολογιστή.

## Αν δεν δουλεύει το Codespaces

Thonny τοπικά με τα ίδια αρχεία. Στο τέλος: github.com → `games` → **Add file → Upload files**.
